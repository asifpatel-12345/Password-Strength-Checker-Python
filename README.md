# 🔑 Password Strength Checker & Generator (Python CLI)

A dual-purpose security utility built in Python that evaluates password security strength using comprehensive criteria and generates highly secure random passwords on demand.

---

## ✨ Features
- **Strength Analysis & Scoring:** Evaluates passwords on a 5-point scale based on length, uppercase/lowercase variety, numbers, and special characters.
- **Smart Feedback:** Provides actionable recommendations to fix weak points in your passwords.
- **Secure Password Generator:** Creates custom-length randomized passwords containing mixed characters and symbols.
- **Zero Dependencies:** Built entirely using Python's native modules (`random`, `string`, `re`).

---

## 🚀 How to Run

1. Make sure **Python** is installed on your system.
2. Clone or download this repository.
3. Open your terminal or VS Code in the project directory.
4. Run the tool using the following command:

```bash
python password_tool.py
